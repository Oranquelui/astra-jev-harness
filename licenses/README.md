# Native distribution notices

The native executable links Go's runtime, `github.com/tree-sitter/go-tree-sitter` v0.25.0 (including Tree-sitter and Unicode tables), `github.com/tree-sitter/tree-sitter-python` v0.25.0, `github.com/mattn/go-pointer` v0.0.1, and `golang.org/x/text` v0.42.0. The Tree-sitter C runtime MIT notice is retained separately as `tree-sitter.txt`. Their notices are retained here and included in platform archives. Additional language grammars in go.sum are transitive test dependencies, not linked runtime dependencies. See go.mod/go.sum for pinned versions and checksums.
